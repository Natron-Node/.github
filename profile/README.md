# Natron Software — Portable Node‑Based Compositing and VFX

## About Natron Software

Natron Software provides professional node‑based compositing and visual effects, serving as a powerful alternative to industry‑standard applications. Natron Software combines node graph workflow, keying (chroma key, difference key), rotoscoping (Bezier masking), motion tracking, 2D transforms, color correction tools, and multi‑layer EXR support. Natron Software supports OpenFX plugin ecosystem, Python scripting for automation, and stereoscopic workflows. Natron Software integrates timeline, curve editor, and export scripts directly into the interface. Natron Software enables VFX artists, compositors, video editors, and motion designers to create film‑quality composites, green screen extractions, and complex visual effects. Natron Software runs on portable storage, USB drives, and local user folders. Natron Software is trusted by VFX artists, independent filmmakers, freelance compositors, video editors, and open source advocates worldwide.
